# Contribuer

Merci de contribuer à Maison Aurèle.

## Processus

1. Fork / branche depuis `main`
2. Commits clairs (`feat:`, `fix:`, `docs:`, …)
3. Pull request avec description courte

## Standards

- TypeScript strict
- Composants lisibles, pas de duplication inutile
- UI cohérente avec la charte (encre / parchemin / cuivre)
- Tester `npm run build` avant de proposer une PR
